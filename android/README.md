# ICLock.apk —— 仪表色块 + 倒计时（最小实现）

装在车机上点一下，就能把「深蓝底 + 大号倒计时 + 八段彩条」推到仪表**全屏**显示，到点自己还原。
**全程不需要电脑**，也不需要 adb —— 应用自己把仪表侧程序投递过去并启动。

- 包名 `com.iclock`　版本 1.0
- 体积 1.7 MB（其中 1.69 MB 是放进 assets 的 armv7 程序）
- minSdk 21 / targetSdk 29，签名 v1+v2+v3

## 装

```bash
adb install -r ICLock.apk
```

或者把 `ICLock.apk` 拷到车机，用文件管理器安装（需允许「未知来源」）。

安装后桌面上叫「仪表投放」。

## 用

1. 车**通电**即可，不用点火。
2. 打开「仪表投放」。
3. **第一次先点「探测」**——只读，不写仪表，用来确认通道成立。
4. 点「投放」，选时长（1/2/5/10/30 分钟），等约 35 秒。
5. 仪表出现画面并开始倒数；到点自动还原。
6. 想提前结束就点「还原」。

## 它在背后做了什么

```
点「投放」
  │
  ├─1. 30510 RPC：在仪表建 /tmp/iclock，清掉上次残留
  │
  ├─2. 本机开 TCP 9971 监听
  │     └─ RPC 让仪表执行  ( sleep 6 ) | nc 172.20.1.45 9971 > /tmp/iclock/bin
  │        （仪表上的 nc 在 stdin EOF 后会立刻退出，所以要用 sleep 顶住）
  │
  ├─3. 仪表回连本机，应用把 assets 里的 1.69 MB armv7 程序发过去
  │     └─ 6 秒后仪表侧自动 chmod 755
  │
  ├─4. RPC：后台启动它，参数是秒数
  │
  └─5. 读运行日志确认 VISIBLE / TICK
```

仪表侧那个程序做的事：

1. 备份 fb1 的 var/fix/blank/显示寄存器 + 整块像素（2.64 MB）到 `/tmp/iclock/original.*`
2. 按原厂 `setmode()` 把 fb1 从 240×320 切到 1920×720
3. 画色块底图，设 alpha=255 / key=1，校验混合态 `com=14 → 15`
4. **每秒只在仪表本地重绘数字区域**，不经过网络
5. 到点或收到 SIGTERM → 切回 240×320、回写像素、比对 hash、复原寄存器

**倒计时是仪表自己算的**，所以不占带宽、不受网络抖动影响，5 分钟倒计时也只用一次投递。

## 失败提示对照

| 日志里出现 | 含义 | 怎么办 |
|---|---|---|
| 连不上 172.20.1.40:30510 | 车没通电 / eth0 不是 172.20.1.45 / 被策略挡 | 点「探测」看网卡列表 |
| 没有找到 172.20.1.45 | 车载网口没起来 | 检查车辆是否上电 |
| 仪表没有连过来（45s 超时） | 仪表侧 `nc` 不可用或被拦 | 这条链走不通，方案止步 |
| 文件没就位或缺可执行位 | 传输被截断 / `/tmp` 有问题 | 重试一次；仍失败看 `df /tmp` |
| REFUSED_BASELINE_GEOMETRY | 显示层不在 240×320 基线 | 点「还原」；无效则断电重启仪表 |
| REFUSED_BASELINE_BLANK | 前景层不是 blank=4 | 同上 |
| REFUSED_BLEND_STATE | 混合态校验没过 | 已自动回滚，把日志发我 |

**兜底**：仪表断电重启。`/tmp` 是 tmpfs 会清空，显示层回到出厂状态，一定安全。

## 已知限制

- **IP 与端口写死在代码里**：`172.20.1.40`（仪表）、`172.20.1.45`（本机）、`30510`。换车或换固件要改代码重编。
- **依赖仪表上的 `nc`**：走的是已经实测可行的「本机监听、仪表回连」方向。
- **只做全屏覆盖，不保留原车内容**。原方案的上下 96/60 行保护带、左右 32px 羽化都没做——那是 `protect()` 的事，这里不需要。
- **不校验 uid**：30510 给的是仪表 root shell，本应用只是「自觉」地只发固定命令，通道本身没有边界。别在这条通道上手动敲写操作。
- **重复投放前会 kill 上一次**并等 4.5 秒让它恢复干净，否则会被基线校验拒绝。

## 从源码重建

```bash
cd android
./build.sh          # 需要 JDK21 + aapt2 + r8.jar + apksig.jar + android-all-12.jar
```

脚本会依次编译 armv7 二进制、编译 Java、生成 dex、aapt2 链接、签名，最后自检 v1/v2/v3。

文件说明：

| 文件 | 作用 |
|---|---|
| `build/iclock.go` | 仪表侧程序的源码（armv7 静态，Go 交叉编译） |
| `src/com/iclock/MainActivity.java` | Android 端：30510 客户端 + 投递 + 启动 |
| `AndroidManifest.xml` | 清单，只有 INTERNET 权限 |
| `build.sh` | 一键构建 |
| `tools/Verify.java` | 签名自检 |
| `preview.png` | 本机渲染的画面预览 |

`build/iclock.go` 里有个隐藏子命令 `iclock dump`，能在本机（macOS/Linux）渲染一帧到 `iclock.ppm`，改版式时不用上车就能看效果。
